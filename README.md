# Document Studio Light

**Document Studio Light** is a lightweight, open-source desktop document editor for Windows and Linux. It is a streamlined version of [Document Studio](https://github.com/fbdn-fantasy/Document-Studio), designed for users who want comprehensive document editing without the additional educational and design workspaces.

Create, edit, format, import, and export documents through a clean and straightforward interface, entirely offline.

## Features

- **Document Editing:** Create and format documents with tables, charts, equations, citations, page layouts, and templates.
- **PDF & Image Import:** Import digital PDFs as editable text and scanned documents or photos as page images.
- **Document Export:** Save documents in DOCX, ODT, PDF, and native editable project formats.
- **Autosave:** Automatically save changes to existing documents with configurable saving intervals.
- **Crash Recovery:** Recover unsaved documents following an unexpected application closure.
- **Spell Checking:** Check spelling using built-in offline dictionaries.
- **Illustrated Ribbon Controls:** Easily access formatting and document editing tools through visual controls.
- **Commands Menu:** Access application commands and interface settings through a dedicated menu.
- **Offline Functionality:** Work without an internet connection using bundled dictionaries, fonts, and document-processing resources.
- **Customizable Appearance:** Choose between System, Light, Dark, and Purple themes.
- **Printing:** Print documents directly from the application.

## Differences from Document Studio

Document Studio Light retains the core document editing functionality of the main application while excluding:

- Optical Character Recognition (OCR).
- 2D and 3D design workspaces.
- Teacher tools and educational workspace.
- Built-in application updater.

## Download & Installation

Document Studio Light is available for **Windows and Linux**.

| Platform | Available Format |
|---|---|
| Windows (x64) | EXE Installer |
| Fedora / RPM-based Linux | RPM Package |
| Debian / Ubuntu-based Linux | DEB Package |
| Other compatible Linux distributions | TAR.GZ Installer |

Download the latest available version from the **[GitHub Releases](../../releases)** page.
